# 💜 Web Player (100% Zero-Server & Zero-Host Standalone App)

A completely standalone, zero-server, zero-host **Web Player** featuring an **Electric Purple & Dark Aesthetic** built with **React**, **Tailwind CSS**, and modern HTML5 Audio.

---

## 🚀 How to Run (NO SERVER & NO HOST REQUIRED!)

You do **NOT** need to run any server, keep any terminal window open, or host this anywhere!

### Option 1: 1-Click Desktop App (Recommended)
Simply **double-click [`start.bat`](file:///C:/Develop/Music%20player/start.bat)** in `C:\Develop\Music player`.
- Launches instantly in a sleek, borderless desktop window (using Edge/Chrome app mode).
- Looks and feels like a native desktop app like Spotify Desktop!
- Runs 100% offline from local disk with **zero background processes**.

### Option 2: Direct Browser Launch
Simply **double-click [`Web Player.html`](file:///C:/Develop/Music%20player/Web%20Player.html)** in `C:\Develop\Music player`.
- Opens directly in your default browser (`file:///...`).
- Self-contained single-file bundle with all HTML, CSS, JavaScript, and SVG icons inlined.
- Plays all local songs from `./audio/` natively without any CORS or network errors.

---

## 🌟 Key Features

1. **🚫 Zero Server, Zero Host, 100% Offline Capable**:
   - No `npm run dev` needed.
   - No cloud hosting or remote backend needed.
   - Everything runs directly on your local machine.

2. **💜 Electric Purple & Dark Aesthetic**:
   - Radiant purple theme (`#a855f7`, `#9333ea`, `#c084fc`) paired with sleek dark surfaces (`#121212`, `#181818`).
   - Dynamic animated purple soundwave bars, glowing range sliders, and purple-accented hero banners.

3. **🎵 Pre-loaded Local High-Fidelity Audio Tracks**:
   - 8 procedural and master tracks included in `audio/`: Synthwave, Lo-Fi, EDM, Acoustic Sunset, Pop Voyage, Electronic Shibuya, Chill Ambient.
   - Works with local audio files directly without network dependencies.

4. **📁 Personal Music Import (Drag & Drop)**:
   - Click **"Import Songs"** or drag-and-drop your own `.mp3`, `.wav`, `.flac`, `.ogg`, or `.m4a` files into the web player to play your personal library!

5. **🔐 Direct Token & Spotify Sync (Optional)**:
   - Paste your Spotify Access Token anytime to stream and sync your original playlists and liked songs.

6. **🎤 Real-Time Karaoke Lyrics & ⚡ Neon Audio Visualizer**:
   - Synchronized lyrics viewer with clickable timestamps.
   - 64-band equalizer spectrum with Equalizer Bars, Circular Pulse, and Neon Waveform.
